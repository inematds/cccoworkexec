🧩 Skills, connectors, plugins

Três mecanismos de extensão que parecem iguais e não são. Skill = unidade de conhecimento. Connector = ponte pra serviço externo via MCP. Plugin = bundle que junta tudo. Saber a diferença evita 90% da confusão em demo.

📁 Skill — pasta com SKILL.md

Uma skill é uma pasta contendo no mínimo um arquivo SKILL.md com frontmatter YAML (name, description). Pode incluir scripts, recursos e instruções. Claude carrega contextualmente quando a descrição bate com a tarefa.

📄 Exemplo mínimo de SKILL.md

---
name: revisar-curso
description: Audita paginas HTML de cursos no formato INEMA.CLUB.
  Use quando o usuario pedir para revisar, auditar ou validar paginas
  HTML de curso existentes.
---

# Revisar Curso

## Quando usar
- Usuario pediu "revisar curso", "checar paginas", "auditar trilhas"
- Ha paginas HTML em curso/trilhaN/ que precisam validacao

## Workflow
1. Listar paginas da trilha alvo
2. Ler index.html e cada modulo-N-M.html
3. Comparar com SPEC.md
4. Reportar inconsistencias por modulo

Estrutura no disco: skills/revisar-curso/SKILL.md (mais scripts/recursos opcionais).

💡 Dica prática

O description é o que importa pro Claude decidir invocar. Escreva como se fosse a "ementa" da skill: o que faz + quando usar + gatilhos típicos. Sem isso, a skill fica engavetada.

🔌 Connector — ponte pra serviço externo

Connectors (também chamados Integrations em claude.ai) ligam Claude a ferramentas externas via servidores MCP remotos. Lançados em maio de 2025. Disponíveis em Pro, Max, Team e Enterprise.

🧰 Serviços no lançamento

  • • Atlassian Jira/Confluence
  • • Zapier
  • • Cloudflare
  • • Intercom
  • • Asana
  • • Square
  • • Sentry · PayPal · Linear · Plaid

🔐 Como conecta

  • • Settings > Connectors em claude.ai
  • • Fluxo OAuth do provedor
  • • Termos e privacy mostrados no flow
  • • Mantido por desenvolvedores terceiros
  • • Google Workspace via Research avançado (Drive/Gmail/Calendar)

📡 MCP Connector na API

// Beta header atual (verificar na doc)
"anthropic-beta": "mcp-client-2025-11-20"

// Anterior, deprecated:
"anthropic-beta": "mcp-client-2025-04-04"

Permite ligar Messages API a servidores MCP remotos sem cliente MCP separado. Custom connectors via Remote MCP estão documentados em support.anthropic.com.

3

📦 Plugin — bundle de extensão

Plugin é o embrulho maior: empacota qualquer combinação de slash commands, subagentes, MCP servers e hooks numa unidade instalável e compartilhável. Public beta no Claude Code.

1

Slash commands

Comandos do tipo /revisar-curso que disparam workflows pré-definidos.

2

Subagentes

Diretório agents/ escaneado recursivamente; pastas viram parte do identificador com escopo.

3

MCP servers

Servidores MCP empacotados que aparecem disponíveis quando o plugin está ligado.

4

Hooks

Pontos de extensão que rodam código em eventos do Claude Code.

💡 Dica prática

Plugins podem ser ligados/desligados conforme necessidade — isso reduz contexto do system prompt. Não deixe todos ativos o tempo todo. Liga só o que vai usar na sessão.

4

📊 Diferenças resumidas

A tabela que resolve a confusão:

Mecanismo Escopo Conteúdo Onde roda
Skill Unidade focada SKILL.md + recursos claude.ai · Claude Code · API
Connector Ponte a serviço externo Servidor MCP remoto claude.ai (Integrations) · API (mcp-connector)
Plugin Bundle multi-componente Slash + subagentes + MCP + hooks Claude Code (public beta)

✓ Quando usar Skill

  • • Workflow repetitivo que precisa de instruções
  • • Conhecimento de domínio que Claude deve "saber"
  • • Quer que invoque automaticamente por relevância
  • • Compartilhar entre claude.ai, Code e API

→ Quando usar Connector/Plugin

  • • Connector: ligar Claude a Jira, GitHub, Drive
  • • Plugin: distribuir conjunto coeso a um time
  • • Plugin: precisa de hooks + subagentes + comandos juntos
  • • Connector: serviço já tem servidor MCP pronto

✗ Confusões comuns

  • • Tratar skill como plugin (skill é unidade, plugin é bundle)
  • • Achar que connector é instalado no Claude Code (é claude.ai/API)
  • • Empacotar tudo em plugin antes de ter skill estável
  • • Ligar 20 plugins e reclamar do contexto inflado

✓ Hierarquia mental

  • • Skill = peça LEGO
  • • Plugin = kit LEGO com manual
  • • Connector = cabo USB pro mundo lá fora
  • • Os três podem coexistir num mesmo projeto
5

🛒 Onde achar — gallery e /plugin

Os três têm caminhos diferentes pra descoberta e instalação. Saber qual é qual te economiza quinze minutos clicando errado.

S

Skills

Pro/Max/Team/Enterprise. Habilita em Settings > Features. Em Team/Enterprise, admin precisa habilitar organization-wide antes. Skills pessoais no diretório próprio do usuário; gallery oficial em construção.

C

Connectors

claude.ai > Settings > Connectors. Diretório oficial mostra connectors mantidos por terceiros. Custom connector via Remote MCP documentado em support.anthropic.com.

P

Plugins

Comando /plugin dentro do Claude Code instala com um único comando. Public beta — ecossistema em formação entre Anthropic e comunidade.

🔎 Onde demonstrar em sala

  • • Sala leiga: mostre Connectors em claude.ai (cara visual, OAuth bonito)
  • • Sala técnica: /plugin no Claude Code instalando algo da galeria
  • • Sala mista: mostre uma skill sendo invocada automaticamente — o "mágico" do description faz efeito

🪄 skill-creator — criar interativamente

A própria Anthropic publica uma skill chamada skill-creator que guia você na criação de novas skills via perguntas. Você descreve o workflow, ela monta pasta, formata SKILL.md e empacota recursos.

🔄 Fluxo do skill-creator

  1. Você chama: "preciso criar uma skill pra revisar páginas HTML do curso"
  2. skill-creator pergunta: quais gatilhos? que arquivos lê? que saída espera?
  3. Itera: testa o description com gatilhos plausíveis pra ver se a skill seria invocada
  4. Empacota: gera skills/nome/SKILL.md + scripts auxiliares se preciso
  5. Você revisa: ajusta o description e o conteúdo manualmente

✓ Quando vale

  • • Primeira skill da vida — você não sabe formato
  • • Workflow ainda em descoberta
  • • Quer testar gatilhos antes de finalizar
  • • Vai compartilhar com gente fora do código

✗ Quando dispensa

  • • Você já escreveu 5 skills — só duplica e edita
  • • Skill mínima de 10 linhas — perde tempo iterando
  • • Você quer estrutura idiossincrática (skill-creator empurra o padrão)

💡 Dica prática

Use o skill-creator pra aprender o formato, depois desenrole sozinho. O grande aprendizado é o jeito de escrever o description: ele decide se sua skill vive ou morre engavetada.
