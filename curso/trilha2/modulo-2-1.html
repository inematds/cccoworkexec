🚲 A metáfora dos 3 produtos

Chat, Cowork e Code não são "versões" um do outro — são veículos diferentes pra terrenos diferentes. Bicicleta pra pedalar até a padaria, CR-V pra família e bagagem, Ferrari pra autopista. Cada um tem seu uso, e insistir no veículo errado é o erro mais caro nos primeiros 30 dias de Claude.

🗺️ Mapa dos 3 produtos

  • 🚲Chat: conversa avulsa em claude.ai. Sem projeto, sem instruções persistentes. Bom pra tarefa única.
  • 🚗Cowork (Projects): chats agrupados num projeto. 200k de contexto, knowledge files, custom instructions. Bom pra workflow recorrente.
  • 🏎️Code: agente no terminal. Lê arquivos, edita código, executa bash, abre PR. Bom pra tarefa multi-passo com ações no disco.

✓ Por que a metáfora funciona

  • ✓Todo mundo já dirigiu/pedalou — vocabulário comum
  • ✓Hierarquia visual clara: leve → médio → potente
  • ✓Faz óbvio que cada um tem seu uso (não é "melhor")
  • ✓Custos diferentes ficam naturais (Ferrari não é grátis)

✗ Erros que a metáfora evita

  • ✗"Claude" tratado como uma coisa só
  • ✗Pular pro Code antes de dominar Chat
  • ✗Achar que Chat "é pra leigo"
  • ✗Pagar Opus pra fazer trabalho de Haiku

💡 Dica prática

Use a metáfora uma vez no início e volte a ela toda vez que apresentar feature nova. "Isso aqui é coisa de CR-V" ou "isso é Ferrari". Vira atalho mental que a sala usa pelo resto da sessão.

💬 Quando usar Chat

Chat avulso em claude.ai resolve ~70% das tarefas pessoais: resumir um artigo, traduzir um e-mail, gerar copy de bio, brainstorm de nomes, explicar um conceito. Não há projeto, não há knowledge file. Cada conversa é uma ilha.

🎯 Onde Chat brilha

  • Tarefas únicas: "traduz esse parágrafo pro inglês"
  • Exploração: "me explica o que é prompt caching"
  • Geração descartável: "5 nomes pro meu projeto novo"
  • Atrito zero: abre o claude.ai, digita, recebe. Sem setup.
A

Tarefa de 1 vez

Sessão única, output descartável

Você precisa traduzir uma carta de apresentação pro inglês. Abre Chat, cola, recebe. Não vai usar de novo. Subir pra Cowork criaria projeto que você nunca mais vai abrir — overhead puro.

B

Brainstorm rápido

Ideação sem persistência

"Me dá 10 ideias de nome pra app de receitas". Você quer variedade ampla, não consistência. Chat é o veículo certo — Cowork com instruções salvas tenderia a viesar.

C

Tirar dúvida técnica

Q&A pontual

"Qual a diferença entre Sonnet e Opus?". Pergunta avulsa, resposta avulsa. Não precisa instalar contexto persistente pra uma curiosidade.

🚗 Quando subir pra Cowork

Cowork = Projects no claude.ai. Disponível em Pro, Max, Team e Enterprise. Cada projeto tem 200k de contexto (~500 páginas), knowledge files até 30 MB cada, e custom instructions que entram em toda conversa do projeto. É o veículo do trabalho recorrente.

🚀 O que Cowork ganha sobre Chat

  • System prompt persistente: "Você é meu copiloto pra revisão de PR. Tom técnico, direto."
  • Knowledge files: seu style guide, sua documentação interna, transcripts de calls — disponíveis em toda conversa
  • 200k tokens: ~500 páginas de contexto efetivo
  • 1 escopo = 1 projeto: "Cliente X" separado de "Cliente Y" separado de "pessoal"

✓ Subir pra Cowork quando

  • ✓Você cola o mesmo system prompt 3+ vezes
  • ✓Você precisa do mesmo arquivo em várias conversas
  • ✓O trabalho tem escopo persistente (cliente, projeto, papel)
  • ✓Outras pessoas vão usar o mesmo fluxo

✗ Não suba pra Cowork quando

  • ✗É a única vez que você vai fazer essa tarefa
  • ✗Contexto muda completamente a cada interação
  • ✗Você está só explorando ideias soltas
  • ✗Plano free (não tem Projects)

💡 Dica prática

Comece com 3 projetos no máximo: "Trabalho", "Pessoal", "Aprendizado". Resista à tentação de criar projeto pra cada mini-tarefa — vira bagunça e você perde a vista. Subdivida depois, quando 1 projeto começar a ficar genérico demais.

🏎️ Quando saltar pra Code

Claude Code é o agente no terminal. Tem 18+ ferramentas (Read, Write, Edit, Glob, Grep, Bash, TodoWrite, Agent, Skill, etc.) e gerencia tarefas multi-step com um loop de planejamento explícito. É a única opção quando a tarefa exige tocar no disco.

🛠️ O que só Code faz

  • Edita arquivos no seu disco: não cola, edita
  • Executa comandos: roda testes, instala deps, faz build
  • Orquestra subagentes: "pesquise A, B, C em paralelo"
  • Mantém plano multi-step: TodoWrite trackia 20+ subtarefas sem perder o fio
  • Abre PR no GitHub: ciclo completo de dev sem sair do terminal

📟 Hello-world do Code (terminal)

# Instalar
npm install -g @anthropic-ai/claude-code

# Rodar
claude

# Dentro do agente, prompt típico:
> Leia o README, identifique os 3 bugs mais
  prováveis e abra PRs separados pra cada um.

✓ Casos onde Code ganha 10x

  • ✓Refatorar 5+ arquivos com testes
  • ✓Adicionar feature em monorepo
  • ✓Investigar bug que cruza várias camadas
  • ✓Migração de framework (Vue 2 → Vue 3)

✗ Casos onde Code é exagero

  • ✗Trocar 1 string num arquivo
  • ✗"Me explica o que esse código faz"
  • ✗Brainstorm de arquitetura sem código
  • ✗Quando você ainda não tem repo (ainda)

💡 Dica prática

A primeira sessão de Code tende a parecer "fora de controle" — é o agente fazendo coisas no seu disco. Use git e branch nova sempre. Aprovação por ação no começo, e só depois libere mais autonomia.

🚨 Sinais de que está no produto errado

Não decida por intuição — decida pelo atrito sentido. Cada sintoma abaixo tem um veículo certo. Quando o atrito repete, troque.

1

Sintoma: você cola o mesmo prompt 3x

Você está no Chat, deveria estar no Cowork

Crie um projeto. Cole o prompt em "custom instructions". A partir da próxima vez, só passe os dados — o sistema injeta o resto.

2

Sintoma: você copia-cola código pro editor

Você está no Cowork, deveria estar no Code

Copy-paste de código é o sinal mais claro pra subir pro Code. O agente edita direto no arquivo, roda os testes e ainda commita. Você só revisa.

3

Sintoma: você criou projeto pra perguntar uma coisa

Você está no Cowork, deveria estar no Chat

Projeto que vira graveyard. Sem reuso, é overhead puro. Desça pro Chat e respire — Projects é pra workflow, não pra pergunta única.

4

Sintoma: Code dá ré em tarefa de 30 segundos

Você está no Code, deveria estar no Chat ou Cowork

Agente abrir terminal pra responder "como faço split de string em Python?" é overkill. Volta pro Chat.

💡 Dica prática

O sentimento de "tô fazendo a mesma coisa de novo" é dado, não emoção. Anote 3 vezes — na 3ª, suba de produto. Esse hábito economiza 1-2h/semana em poucas semanas.

💰 Pricing e quando o custo justifica subir

Chat e Cowork seguem o plano do claude.ai. Code consome API por token — e é aí que aparece a confusão. Quando você mostra a tabela e o cálculo de ROI, o ceticismo some.

📊 Tabela de bolso (Claude 4.x, 2026)

Modelo        Input/MTok   Output/MTok   Contexto
Haiku 4.5     $1           $5            200k
Sonnet 4.6    $3           $15           1M
Opus 4.7      $5           $25           1M

Prompt caching read = 10% do input padrão
Batch API       = 50% off em ambos

🧮 Cálculo de ROI simples

Uma sessão típica de Claude Code pra fechar uma feature pequena (Sonnet 4.6, ~100k input + 30k output, com caching):

  • Input sem cache: 100k × $3/MTok = $0,30
  • Com caching (90% hit): ~$0,06
  • Output: 30k × $15/MTok = $0,45
  • Total: $0,30 — $0,75 por sessão
  • Compara com: 2-4h de dev humano. Não tem competição.

✓ Argumentos que viram a sala

  • ✓Mostre o cálculo $0,30/sessão ao vivo
  • ✓Compare com hora-dev (R$ 150-300/h)
  • ✓Prompt caching reduz 60-90% em uso real
  • ✓Batch API pra workloads assíncronos: -50%

✗ Argumentos que NÃO usar

  • ✗"É barato" (sem número, não convence)
  • ✗"Vale a pena pra qualquer caso"
  • ✗Comparar com ChatGPT Plus (planos ≠ API)
  • ✗Defender Opus em volume alto (use Haiku)

💡 Dica prática

Mostre o painel de uso da API no console.anthropic.com ao vivo. Saber que você gastou $4,80 no mês inteiro de Claude Code desliga 90% do ceticismo financeiro na sala.
