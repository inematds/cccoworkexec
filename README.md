# Ensinando Claude Cowork

Playbook de campo para conduzir treinamentos corporativos de Claude Cowork em salas de 10 a 300 pessoas.

**Site:** https://inematds.github.io/cccoworkexec/

## Estrutura

5 trilhas, 27 módulos:

- **T1 — Enquadramento e Autoridade** (3 módulos)
- **T2 — Três Produtos + Modelos Mentais** (6 módulos)
- **T3 — Pré-produção de Demos** (6 módulos)
- **T4 — Tour Guiado da Interface** (9 módulos)
- **T5 — Fechamento e Continuidade** (6 módulos)

## Formato

HTML estático com Tailwind CDN. Sem build step — abre direto no browser ou via GitHub Pages.

Padrão visual: [INEMA.CLUB](https://inema.club).

## Ativar GitHub Pages

`Settings → Pages → Source: Deploy from a branch → main → / (root) → Save`
